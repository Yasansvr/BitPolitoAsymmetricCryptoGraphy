Why does this work? For any point on y² ≡ x³ + 7 (mod p), solving for y yields two symmetric square roots: +y and -y ≡ p - y. Because the prime p is odd, one root is always even and the other is always odd. By saving 02 (even) or 03 (odd) plus the 32-byte x coordinate, the full point is uniquely defined while saving 32 bytes!

Bitcoin passes the public key bytes through SHA-256 first. This produces a fixed 256-bit (32-byte / 64 hex) digest, providing pre-image resistance and a standardized size.

Step 3 of 6

RIPEMD-160 Hash Function (PubKeyHash)

The 32-byte SHA-256 digest is fed into RIPEMD-160 to create a compact 160-bit (20-byte / 40 hex) Public Key Hash (PubKeyHash / Hash160).
Why two hash algorithms? If an unexpected theoretical weakness is ever found in SHA-256 or ECDSA, RIPEMD-160 still shields unspent coins!

Bitcoin Elliptic Curve Cryptography

secp256k1 Parameter & Asymmetric Encryption Architecture

Plot of y² = x³ + 7 with Base Generator Point G
1. Curve Equation & Parameters
Bitcoin uses the elliptic curve secp256k1 defined over the finite prime field Fp:
y² ≡ x³ + 7 (mod p)
p = 2²⁵⁶ − 2³² − 977 (0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEFFFFFC2F)
2. Private & Public Key Derivation
• Private Key (d): A randomly generated 256-bit secret scalar: 1 ≤ d < n
• Public Key (Q): A point on the curve obtained by multiplying base generator point G by scalar d:
Q = d · G = G + G + … + G (d times)
Because of the Elliptic Curve Discrete Logarithm Problem (ECDLP), it is computationally impossible to deduce the secret d from the public point Q.
3. How Asymmetric Encryption (ECIES) Works
1. Sender generates an ephemeral random secret k and computes ephemeral public point R = k · G.
2. Sender computes shared secret point S = k · Qreceiver.
3. Sender derives symmetric key K = SHA-256(Sx) to encrypt the message (AES-256-GCM).
4. Receiver receives (R, ciphertext) and uses their private key d:
S = dreceiver · R = d · (k · G) = k · (d · G) = k · Qreceiver = S
Both parties compute the exact same secret point S without ever transmitting their private keys over the wire!
